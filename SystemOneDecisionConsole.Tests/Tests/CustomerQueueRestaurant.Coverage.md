# Customer, work queue, and restaurant native coverage

The original inventory contains **374 functionality checks** in these assigned blocks: 137 customer checks (including the later failed-repeat workflow), 108 work queue checks, and 129 restaurant checks. Three checks invoke temporary compiled harnesses; those are now covered by the separate native `BinaryEvaluationHarnessTests`, `WorkQueueHarnessTests`, and `RestaurantHarnessTests` classes. The scenario classes here contain the remaining **371 functionality cases**. Each case starts from an isolated complete console output and uses an in-process TCP fixture server. No test invokes Python or compiles a temporary harness.
